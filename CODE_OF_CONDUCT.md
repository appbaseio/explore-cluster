# Code of Conduct

## Our standard

We expect contributors and maintainers to be respectful, constructive, and professional in all project interactions.

## Unacceptable behavior

- Harassment, discrimination, or abusive language
- Personal attacks or trolling
- Publishing private information without permission

## Scope

This Code of Conduct applies in all project spaces, including issues, pull requests, and discussions.

## Reporting

For conduct concerns, please open a private security/contact report as documented in `SECURITY.md`.
